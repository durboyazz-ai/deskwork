## 5. Running the Prototype

### 5.1 Prerequisites

- **Docker** (for the backend + DB)
- **Node.js v20+** (for the frontend)

> *If you don’t want to use Docker, just run* `pip install -r backend/requirements.txt` *and* `npm ci` *inside each folder.*
